Images and printer drivers

Prints a picture as black and white dots through a printer driver: ESC/POS for the usual 58/80 mm receipt printers, or the Phomemo M02 and M02 Pro, which need their own commands. The page turns the picture into a 1-bit bitmap, shows it below and sends it to the printer of the "Printer" card (the first print opens Chrome's list if no printer is paired yet).

Advanced

Text is sent in Windows-1252. If accented letters come out wrong, look for "WPC1252" or "1252" on the printer's self-test page (it is usually printed by holding FEED while turning the printer on) and write its number here. It is almost always 16.

Automatic: with response in 100-byte chunks if the printer allows it, otherwise 20 bytes with short pauses; if the printer refuses 100-byte chunks the page switches to 20 by itself. Change the mode only if the print comes out incomplete or with random characters.

Diagnostics shows only the services this page declares to the browser (known serial channels of thermal printers): any other service stays invisible under the Web Bluetooth rules. If your printer exposes no writable characteristic here, use the Print Bridge app.

Help
  • Pair once. Choose the printer in Chrome's list once: as long as this tab stays open, prints start without further confirmations and the page reconnects by itself. After a reload or a new visit, one tap on "Reconnect" (or directly on a print) and on the printer in the list is enough.
  • Remember it between visits too. Chrome does this only with the experimental option chrome://flags/#enable-web-bluetooth-new-permissions-backend set to "Enabled" (then restart Chrome): from then on the page reconnects when it opens, with no taps.
  • The printer does not show up. Turn it on and bring it closer. If it is connected to something else (the Print Bridge app, another phone, a PC) it stays hidden: disconnect it, or turn it off and on again. Also try "I can't find the printer in the list", which shows all devices.
  • Android 11 or earlier. Chrome needs the Location permission and Location must be on, otherwise it finds no Bluetooth devices.
  • Dual-mode printers (for example Netum NT-1809 and NT-1809DD): over BLE they often show up with a different name, such as "BlueTooth Printer". There is no need to pair them in the Android Bluetooth settings.
  • Bluetooth Classic only printers (SPP): Web Bluetooth does not see them. Pair them in the system settings and print from the serial printing page (Web Serial) with Chrome or Edge on a computer, or with Chrome 138 or later on Android. On Android without Chrome 138 or later, use the Print Bridge app and the test page.
  • On a computer: printers that are not BLE. USB printers and Bluetooth Classic printers paired in the system can be reached from the serial printing page (Web Serial: Chrome and Edge; Firefox 151 or later for USB printers only).
  • Random characters or interrupted print. In "Advanced" choose a slower sending mode. Wrong accents: set the code page in "Advanced".
  • iPhone, iPad, Firefox and Safari do not support Web Bluetooth: use Chrome on Android (or Chrome and Edge on a computer).
