Print Bridge

From a web page to a thermal printer

|

What it is

Print Bridge prints receipts, tickets and labels from a web page on a thermal printer: ESC/POS receipt printers (58 and 80 mm) and the Phomemo M02 and M02 Pro. The page loads one script, escpos.js, builds the receipt (text, QR codes, logo, or a layout filled with data) and sends it to the printer in one of three ways:

  • Android app. For any Bluetooth Classic printer paired in Android: the page hands the receipt to the app on the same device, and the app prints it.
  • Web Bluetooth. For Bluetooth LE printers, straight from Chrome on Android, or Chrome and Edge on a computer, without installing anything.
  • Web Serial. For USB printers and Bluetooth Classic printers paired in the system from Chrome or Edge on a computer, for USB printers from Firefox 151 or later on a computer, and for Bluetooth Classic printers from Chrome 138 or later on Android.

Everything stays on the device: the receipt goes from the page to the printer, or to the app on the same device, never through an online service.

Use it in your page

Load escpos.js from the CDN (or from your own site) and print a layout filled with your data. In production pin an exact version instead of @1 (for example @1.13.0) or serve the file yourself:

<button id="print">Print</button>
<script src="https://cdn.jsdelivr.net/npm/@nb-camelot/rawbt-print@1/escpos.js"></script>
<script>
  var LAYOUT = {
    paper: 58,
    blocks: [
      { text: '{{shop}}', align: 'center', bold: true, size: [2, 2] },
      { rule: true },
      { each: 'items', row: ['{{qty}} x {{name}}', '{{price|euro}}'] },
      { rule: '=' },
      { row: ['TOTAL', '{{total|euro}}'], bold: true },
      { qr: '{{qr}}', size: 5 },
      { feed: 3 },
      { cut: true }
    ]
  };
  document.getElementById('print').onclick = function () {
    // In the tap handler: the printer chooser needs the tap.
    RawBT.printLayout(LAYOUT, {
      shop: 'Demo Shop',
      items: [{ qty: 2, name: 'Espresso', price: 2.4 }],
      total: 4.8,
      qr: 'https://example.com/r/A-042'
    }).then(function (r) {
      if (!r.ok && !r.cancelled) alert(r.error);
    });
  };
</script>

Without a via, RawBT.printLayout picks the way by itself: the one saved with RawBT.setVia, a printer already chosen in this tab (BLE or serial), the app if RawBT.check() found it, a printer used on an earlier visit, otherwise the app. { via: 'ble' }, 'serial' or 'app' fixes one.
